2. GOALS, NON-GOALS, SUCCESS METRICS
================================================================================

Goals
  G1  A visitor goes from an idea to a live, shareable React app in under
      60 seconds, with no sign-up.
  G2  A developer connects any MCP client to spike.land with one config
      snippet and discovers tools progressively, without bloating context.
  G3  Show off the platform through first-party apps that are themselves
      built from MCP tools.
  G4  Keep the core free; monetize power users (Orbit, Pixel, credits).
  G5  Establish thought leadership (BAZDMEG, blog, LearnIt) to bring in
      organic traffic.

Non-goals
  - Native mobile apps (a PWA is enough)
  - A full photo-editing suite (Pixel focuses on AI enhancement only)
  - Self-hosted enterprise deployments (beyond the open-source repo)

Success metrics (suggested)
  - Time to first generated app (TTFA) p50 < 30 s
  - % of /create generations reaching "Published" > 80%
  - Weekly active MCP connections; number of tool calls per session
  - Free → paid Orbit conversion within 30 days
  - Skill installs; app views (shown on cards, e.g. "167 views")
  - Performance targets from the docs: 99.9% uptime, API p50 < 200 ms,
    p95 < 500 ms, AI drafts < 3 s, error rate < 0.1%

7. FEATURE: VIBE CODING / AI APP BUILDER
================================================================================

Routes: /create (builder), /create/[...path] (generated app viewer). Any
unknown top-level path triggers generation too.

7.1 /create page
  - Shell header: "CodeSpace — Live React code editor with AI assistance" with
    an "App Info" link and a "Store" breadcrumb.
  - H1 "Describe it. We build it."
  - Copy: "Type any app idea and watch AI generate a fully working React app
    in seconds. No setup, no boilerplate — just describe what you want."
  - Prompt input "Describe the app you want to create". Submit with the
    "Create" button or ⌘+Enter.
  - Suggestion chips: Todo List, Calculator, Color Picker, Markdown Editor,
    Pomodoro Timer, Weather Widget, Quiz App, Habit Tracker.
  - "Popular Apps" grid sorted by views (title, view count, description,
    "Open App"), e.g. Musical Hexagons (280), Alarm Sound Studio (183),
    Glass Calc Pro (167) …

7.2 Generation pipeline (visible stepper)
  Planning → Plan Review → Coding → Transpiling → Code Review → Published
  - Header shows "Building your app... Generating /<slug>".
  - The prompt becomes a URL slug; nested paths are allowed
    (e.g. /create/roadmap/next-2-weeks/human-on-the-loop/dev-agency).
  - Self-correcting: the agent learns from earlier failures (blog: "The Vibe
    Coding Paradox").
  - Transpilation runs on an esbuild-wasm Cloudflare Worker (js.spike.land);
    live apps run on testing.spike.land codespaces.

7.3 Generated app viewer (/create/<slug>)
  - Breadcrumb "All Apps / create"; title and slug label.
  - The live app runs in a sandboxed preview.
  - "Create Your Own" CTA; "More Apps" list.
  - Hint: "Try typing any path in the URL to generate a new app!"
  - The view counter goes up on each visit.

7.4 My Apps (signed in) — managed through the "apps" MCP category / /api/apps
  - Create from prompt, chat to iterate, read the message history.
  - Immutable code versions, with listing and restore.
  - Status changes (ARCHIVED stops the live app).
  - Recycle bin: soft-delete for 30 days, restore, permanent delete.
  - Batch status changes (agent-only), clear messages, image upload.

Functional requirements
  FR-7.1  Anonymous users can generate and view apps.
  FR-7.2  Each generation persists: slug, title, description, code, status
          and views.
  FR-7.3  Progress streams to the client in real time (SSE/WebSocket).
  FR-7.4  If generation fails, show the failed stage and let the user retry.
  FR-7.5  Generated apps are public and indexable, with a per-app title and
          description.

8. FEATURE: MCP SERVER & TOOLS
================================================================================

8.1 /mcp landing
  - Badge "Progressive Disclosure MCP"; H1 "455 AI Tools. One Protocol."
  - Copy: agents start with 5 lightweight gateway tools and progressively
    discover 455 tools across 88 categories.
  - Stats: 455 Tools, 88 Categories, 5 Gateway Tools.
  - Config (.mcp.json):
      { "mcpServers": { "spike-land": {
          "url": "https://spike.land/api/mcp",
          "headers": { "Authorization": "Bearer YOUR_API_KEY" } } } }
  - "Explore Tools" button.
  - Interactive Playground: "Browse Tools" → "Select a tool". The list of
    available tools is grouped into 8 super-categories:
      Platform Core 47 | Development 69 | AI & Creative 60 |
      Content & Media 55 | Marketing & Growth 50 | Commerce & Admin 44 |
      First-Party Apps 62 | Agents & Automation 60
    Selecting a tool shows a try-it form generated from its schema. Running
    it needs an API key.
  - "spike.land MCP Terminal": a simulated terminal showing tool calls.
  - "How It Works", 3 steps:
      1 Connect (5 tools): search_tools, list_categories, enable_category,
        get_balance, get_status
      2 Discover (8 tools): search_tools("image") adds generate_image,
        modify_image, check_job
      3 Activate (34 tools): enable_category loads the full category
  - "Tool Categories": "Browse 88 categories and 455 tools with inline try-it
    forms" → /docs/tools
  - "Get Connected" tabs: Claude Desktop | Claude Code | Cursor | HTTP, each
    with a config snippet and a "Copy code" button. "Need an API key? Go to
    Settings."

8.2 Transport & auth
  - Streamable HTTP endpoint /api/mcp; SSE endpoint /api/mcp/sse.
  - Bearer API key, created in Settings or with settings_create_api_key. The
    key is shown once, stored masked, and can be revoked.
  - Tools are tagged with a tier: "free" or "workspace" (workspace tools need
    workspace context or a subscription).
  - Credit-consuming tools check the balance (get_balance) and refund on
    failure.
  - MCP job history (settings_mcp_history, settings_mcp_job_detail).

8.3 Progressive Context Disclosure (core requirement)
  - On connect, ONLY the 5 gateway-meta tools are registered.
  - search_tools(query) returns matches and registers them dynamically.
  - enable_category(name) registers the whole category.
  - Send notifications/tools/list_changed after any change.

8.4 /docs/tools catalogue
  - Grid of 88 category cards (name, tool count, description, tier badge).
  - /docs/tools/[category]: the tool list (name, category, tier, description,
    parameter count) with inline try-it forms.
  - The full category list is in Appendix A.
