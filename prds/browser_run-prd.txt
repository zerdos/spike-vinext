1. EXECUTIVE SUMMARY & VISION
================================================================================
Modern autonomous AI coding agents (Claude Code, Cursor, Windsurf, Roo Code, 
multi-agent workflows) increasingly depend on live web automation—navigating dynamic 
Single Page Apps (SPAs), capturing visual UI states, extracting rendered DOM trees, 
crawling documentation hierarchies, extracting clean LLM markdown, and diagnosing 
web applications via the Chrome DevTools Protocol (CDP).

Historically, integrating headless browser automation into AI toolchains required:
1. Managing bloated Docker containers running Chromium grids (Selenium/Puppeteer), 
   which introduce high cold starts (5-30s), heavy memory footprints (1-2 GB per 
   instance), and complex cluster orchestration.
2. Relying on centralized third-party web scrapers that add external network hops, 
   unpredictable latency spikes, and fragile session state.
3. Overwhelming the agent's context window by disclosing dozens of granular browser 
   methods upfront, destroying upstream LLM prompt caches (Position-Zero cache 
   invalidation).

The Spike Land **Browser Run** integration delivers a zero-container, edge-native 
headless browser automation platform running directly on **Cloudflare Workers** 
using the official Cloudflare Browser Rendering / Browser Run binding (`env.BROWSER`). 

Key Capabilities:
- **Instant Cold Starts (< 5ms):** Runs Chromium instances orchestrated across 
  Cloudflare's global edge network (300+ cities).
- **18 Specialized Tools:** Spanning single-turn Quick Actions, multi-page deep 
  crawling with Content Signals compliance, interactive Human-in-the-Loop Live View, 
  typed DevTools inspections, and raw WebSocket Chrome DevTools Protocol (CDP) commands.
- **3-Tier Execution Resilience:** Automatic failover across native Worker bindings, 
  Cloudflare REST APIs, and a 100% deterministic local edge simulation engine for 
  offline, local dev, and automated testing environments.
- **MCP 2026-07-28 Conformance:** Fully compatible with latest stateless MCP 
  standards, SEP-2243 header mismatch guards, SEP-2575 versioning, RFC 9728 OAuth 2.1 
  resource metadata, and SEP-2549 cache-preserving Progressive Context Disclosure.

================================================================================
2. PROBLEM STATEMENT & MOTIVATION
================================================================================
Browser automation for AI agents faces four acute challenges:

1. **The Infrastructure Burden of Headless Chromium:**
   Traditional browser automation requires long-running container fleets. For 
   serverless or edge-native platforms like Spike Land, running Dockerized Chromium 
   locally inside V8 isolates is impossible. Leveraging Cloudflare's Browser Rendering 
   infrastructure at the edge eliminates all container lifecycle overhead.

2. **LLM Context Exhaustion & Position-Zero Cache Busting:**
   Declaring 18 complex browser tools with extensive JSON Schemas upfront injects 
   ~15,000 tokens into the prompt context. Mutating the tool list mid-stream invalidates 
   the LLM's Position-Zero prompt prefix cache, increasing latency by 5x-10x and 
   multiplying token billing costs. Progressive Disclosure is required to expose 
   browser capabilities on demand.

3. **Development vs. Production RPC Divergence:**
   In local development (`wrangler dev` or `vite dev`), calling native Cloudflare 
   browser bindings can throw `Browser execution is not supported without a remote 
   connection` or fail when offline. A robust abstraction layer must provide seamless 
   fallback to the Cloudflare REST API and a fully deterministic local edge mock 
   engine without changing tool contracts.

4. **Human-in-the-Loop Takeover & Visual Verification:**
   Autonomous agents navigating complex flows (login hurdles, bot verification, 
   visual layout debugging) require real-time observation and safe human takeover 
   without leaking full write access to the underlying session.

3. ARCHITECTURAL OVERVIEW & 3-TIER EXECUTION ENGINE
================================================================================
The Browser Run architecture is built on a resilient, three-tier hierarchical 
execution dispatcher implemented in `lib/browser-run.ts`. Every tool invocation 
traverses this pipeline:

```
┌────────────────────────────────────────────────────────────────────────┐
│                         Tool Invocation Request                        │
│   (via MCP JSON-RPC, REST Endpoint, Pattern B Broker, or Pattern C VG) │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│            Tier 1: Cloudflare Native Binding (`env.BROWSER`)           │
│  - Inspects execution context for attached Browser Run binding         │
│  - Executes native `env.BROWSER.quickAction()`, `.acquire()`, etc.     │
└───────────────────┬────────────────────────────────▲───────────────────┘
                    │                                │
            Throws "non-remote"                      │ Success
            or Binding Missing                       │
                    ▼                                │
┌───────────────────────────────────────────────────┐│
│            Tier 2: Cloudflare REST API            ││
│  - Checks `CLOUDFLARE_ACCOUNT_ID` & `_API_TOKEN`  ││
│  - Routes to `api.cloudflare.com/client/v4/...`   ││
└───────────────────┬───────────────────────────────┘│
                    │                                │
            Missing Credentials                      │
            or Offline / Test Env                    │
                    ▼                                │
┌───────────────────────────────────────────────────┐│
│   Tier 3: Local Edge Deterministic Mock Engine    ││
│  - Pure edge V8 execution with zero network deps  ││
│  - High-res synthetic PNG generation (CRC32/zlib) ││
│  - In-memory session store & crawl state machine  ││
│  - Fast regex/DOM parser for Markdown & AX Tree   ││
└───────────────────┬───────────────────────────────┘│
                    │                                │
                    ▼                                ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        Normalized JSON Response                        │
│    (Standardized MCP Text Content, Base64 Assets, or REST JSON)        │
└────────────────────────────────────────────────────────────────────────┘
```

3.1 Tier 1: Native Cloudflare Workers Browser Run Binding (`env.BROWSER`)
When deployed on Cloudflare Workers with `bindings.browser()` declared in 
`cloudflare.config.ts`, the runtime provides an `env.BROWSER` object exposing:
- `quickAction(action, options)`: Instant single-turn execution for 9 action types.
- `acquire(options)`: Allocates an active browser session on Cloudflare's browser grid.
- `launch(options)`: Acquires and initiates a direct WebSocket session connection.
- `connectSession(sessionId, options)`: Reconnects to an active running session.
- `getLiveView(sessionId, options)`: Mints authenticated Live View URLs.
- `listSessions()` & `history()`: Session monitoring and historical inspection.
- `limits()`: Current concurrency and browser time quota usage.
- `getSession(sessionId)` & `closeSession(sessionId)`: Lifecycle controls.
- `devtools`: Typed DevTools JSON endpoints (`getVersion`, `getProtocol`, 
  `listTargets`, `getTarget`, `newTarget`, `activateTarget`, `closeTarget`).

3.2 Tier 2: Cloudflare Client REST API Fallback
When running in local dev or intermediate proxies where `env.BROWSER` is absent or 
throws the non-remote local RPC error (`"Browser execution is not supported without a 
remote connection"`), the engine automatically checks for:
- `CLOUDFLARE_ACCOUNT_ID`
- `CLOUDFLARE_API_TOKEN`
If present, requests are proxied via standard HTTPS to:
`https://api.cloudflare.com/client/v4/accounts/${accountId}/browser-rendering/...`
with Bearer token authentication.

3.3 Tier 3: Local Edge Deterministic Simulation Engine
For local testing, CI/CD pipelines, offline development, or environments lacking 
Cloudflare credentials, the engine falls back to a deterministic edge simulator:
- **Synthetic Screenshot Generator:** Generates valid, high-resolution PNG image 
  byte streams with standard PNG headers (`IHDR`, `IDAT`, `IEND`), zlib DEFLATE 
  scanlines, and CRC-32 checksum calculation.
- **Deterministic DOM / Markdown Parser:** Performs clean HTML tag stripping, header 
  normalization, hyperlink conversion (`[text](url)`), and list extraction.
- **Accessibility Tree Synthesizer:** Builds structured AX trees with standard roles 
  (`RootWebArea`, `heading`, `link`, `StaticText`) and handles `interestingOnly` 
  and `root` selector scoping.
- **In-Memory Session & Crawl Stores:** `localSessionsStore` and `localCrawlJobsStore` 
  provide stateful session management, pagination cursors, and crawl progress tracking.
- **Exported State Reset:** `resetBrowserRunLocalState()` allows isolated test fixtures.

4. COMPLETE CATALOG OF 18 BROWSER RUN TOOLS
================================================================================
All 18 tools are defined with JSON Schema 2020-12 parameter schemas, explicit 
annotations (`readOnlyHint`, `idempotentHint`, `openWorldHint`), risk tiers 
(`low-readonly`), and SEP-1865 MCP Apps UI resource URIs (`uiResourceUri`).

--------------------------------------------------------------------------------
4.1 Quick Actions Suite (9 Tools)
--------------------------------------------------------------------------------
Quick Actions provide zero-session, single-turn browser rendering operations. Either 
`url` (HTTP/HTTPS URL) or `html` (raw HTML string) is required.

Common Configuration Parameters across Quick Actions:
- `url` (string): Webpage URL to navigate to.
- `html` (string): Raw HTML string to render directly.
- `gotoOptions` (object): Navigation control:
  - `waitUntil`: `'load'` | `'domcontentloaded'` | `'networkidle0'` | `'networkidle2'`.
  - `timeout`: Navigation timeout in milliseconds (default: 30000).
  - `referer`: Custom HTTP referer header.
- `waitForSelector` (object): CSS selector to wait for before capturing:
  - `selector`: CSS selector string.
  - `timeout`: Wait timeout in ms.
  - `visible`: Wait until element is visible in DOM.
  - `hidden`: Wait until element is hidden.
- `viewport` (object): Viewport dimensions (`width`, `height`, `deviceScaleFactor`, 
  `isMobile`, `hasTouch`, `isLandscape`).
- `rejectResourceTypes` (string[]): Block assets to save bandwidth (`'image'`, 
  `'stylesheet'`, `'font'`, `'media'`).
- `rejectRequestPattern` (string[]): Regex patterns of network URLs to abort.
- `allowResourceTypes` / `allowRequestPattern`: Whitelist rules.
- `userAgent` (string): Custom browser User-Agent.
- `setExtraHTTPHeaders` (object): Custom HTTP headers for outbound requests.
- `cookies` (array): Pre-injected session cookies (`name`, `value`, `domain`, etc.).
- `authenticate` (object): HTTP Basic Auth credentials (`username`, `password`).
- `addScriptTag` / `addStyleTag`: Injected `<script>` or `<style>` elements.
- `setJavaScriptEnabled` (boolean): Enable/disable JS execution.

4.1.1 `browser_run_content`
- **Purpose:** Renders a URL or raw HTML in headless Chromium and returns the fully 
  hydrated, post-JavaScript DOM HTML.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_content`
- **Output:** `{ success: true, action: "content", mode: "binding"|"rest"|"edge", result: "<!DOCTYPE html>..." }`

4.1.2 `browser_run_markdown`
- **Purpose:** Renders dynamic page content and converts the resulting DOM into clean, 
  token-optimized Markdown for LLM consumption.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_markdown`
- **Output:** `{ success: true, action: "markdown", mode: "...", result: "# Title\n\nContent..." }`

4.1.3 `browser_run_screenshot`
- **Purpose:** Captures visual screenshots of full pages or targeted DOM elements.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_screenshot`
- **Specific Parameters:**
  - `selector` (string, optional): Capture only the bounding box of a specific element.
  - `screenshotOptions`:
    - `fullPage` (boolean): Capture entire scrollable page height.
    - `type` (`'png'` | `'jpeg'` | `'webp'`).
    - `quality` (number): 0-100 for JPEG/WebP.
    - `clip`: `{ x, y, width, height, scale }`.
    - `omitBackground` (boolean): Transparent background.
- **Output:** `{ success: true, action: "screenshot", format: "png", data: "data:image/png;base64,..." }`

4.1.4 `browser_run_pdf`
- **Purpose:** Generates print-accurate PDF documents from web pages or raw HTML.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_pdf`
- **Specific Parameters:**
  - `pdfOptions`:
    - `format`: `'letter'` | `'legal'` | `'tabloid'` | `'ledger'` | `'a0'`-`'a6'`.
    - `landscape` (boolean).
    - `displayHeaderFooter` (boolean).
    - `headerTemplate` / `footerTemplate` (string: HTML).
    - `printBackground` (boolean).
    - `pageRanges` (string: e.g. `'1-5, 8'`).
    - `margin`: `{ top, right, bottom, left }`.
- **Output:** `{ success: true, action: "pdf", format: "pdf", data: "data:application/pdf;base64,..." }`

4.1.5 `browser_run_snapshot`
- **Purpose:** Multi-format atomic snapshot bundling content, markdown, screenshot, 
  and accessibility tree in a single round-trip.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_snapshot`
- **Specific Parameters:**
  - `formats` (array): Selection of `['content', 'markdown', 'screenshot', 'accessibilityTree']`.
  - `screenshotOptions`: Sub-options for the visual capture.
- **Output:** Object containing requested formats simultaneously.

4.1.6 `browser_run_accessibility_tree`
- **Purpose:** Extracts the Chrome Accessibility (AX) Tree for semantic hierarchy analysis, 
  screen-reader testing, or structured element navigation.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_accessibility_tree`
- **Specific Parameters:**
  - `interestingOnly` (boolean, default: true): Exclude generic or unexposed nodes.
  - `root` (string, optional): Root element selector to scope the tree inspection.
- **Output:** Structured hierarchy of accessibility nodes (`role`, `name`, `level`, `children`).

4.1.7 `browser_run_scrape`
- **Purpose:** Targeted element extraction via CSS selectors, returning bounding box 
  geometry (`width`, `height`, `top`, `left`), inner text, HTML, and attribute arrays.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_scrape`
- **Specific Parameters:**
  - `elements` (array, required): Array of `{ selector: string }`.
- **Output:** Array of matched selectors with bounding boxes and attribute key-value pairs.

4.1.8 `browser_run_json`
- **Purpose:** Executes LLM-driven structured JSON extraction from webpage content 
  against an arbitrary JSON Schema.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_json`
- **Specific Parameters:**
  - `prompt` (string): Extraction instruction or query.
  - `response_format`: `{ type: "json_schema", json_schema: { ... } }`.
  - `custom_ai`: Array of `{ model: string, authorization?: string }`.
- **Output:** Schema-validated JSON extracted from the page.

4.1.9 `browser_run_links`
- **Purpose:** Discovers and normalizes all hyperlinks within a webpage.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_links`
- **Specific Parameters:**
  - `visibleLinksOnly` (boolean): Exclude hidden/invisible links.
  - `excludeExternalLinks` (boolean): Restrict results to the page's host domain.
- **Output:** `{ success: true, action: "links", links: ["https://..."] }`

4.2 Multi-Page Web Crawler Suite (3 Tools)
--------------------------------------------------------------------------------
The crawler engine orchestrates asynchronous multi-page crawling at the edge.

4.2.1 `browser_run_crawl_start`
- **Purpose:** Initiates a background crawl job across links or sitemaps.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_crawl_start`
- **Parameters:**
  - `url` (string, required): Seed URL.
  - `limit` (number, default: 10): Max pages to crawl.
  - `depth` (number, default: 2): Max crawl link depth.
  - `source` (`'all'` | `'sitemaps'` | `'links'`).
  - `formats` (array: `'html'` | `'markdown'` | `'json'`).
  - `render` (boolean): Whether to execute JavaScript on each page.
  - `includePatterns` / `excludePatterns` (string[]): Glob or regex filters.
  - `crawlPurposes` (string[]): Declares crawl intent (`['search', 'ai-input', 'ai-train']`).
  - `contentUse` (string): Content Signals Policy declaration (`'immediate'`, `'reference'`, `'full'`).
- **Output:** `{ success: true, job_id: string, status: "running"|"completed", total: number, finished: number }`

4.2.2 `browser_run_crawl_status`
- **Purpose:** Polls progress and retrieves crawled page records with pagination and status filters.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_crawl_status`
- **Parameters:**
  - `job_id` (string, required): Job identifier.
  - `cursor` (number, optional): Offset cursor for pagination.
  - `limit` (number, optional): Max records to return.
  - `status` (`'queued'` | `'completed'` | `'disallowed'` | `'skipped'` | `'errored'` | `'cancelled'`).
- **Output:** `{ job_id, status, browserSecondsUsed, total, finished, records: [...], next_cursor }`

4.2.3 `browser_run_crawl_cancel`
- **Purpose:** Terminates an ongoing crawl job immediately.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_crawl_cancel`
- **Parameters:**
  - `job_id` (string, required).
- **Output:** `{ success: true, job_id, status: "cancelled_by_user" }`

4.2.4 Content Signals Policy & AI Training Compliance
The crawler enforces Cloudflare's Content Signals Policy:
- When a website or crawl request specifies `contentUse: "immediate"`, the crawler 
  restricts storage and processing to immediate real-time response generation and 
  prohibits long-term training indexing (`"disallowed"` status).
- Standard `robots.txt` disallow rules and `crawlPurposes` headers are honored at the edge.

4.3 Browser Sessions, Live View, DevTools & CDP Suite (6 Tools)
--------------------------------------------------------------------------------
For interactive workflows, stateful multi-step interactions, and human inspection:

4.3.1 `browser_run_session_acquire`
- **Purpose:** Allocates a persistent browser session on Cloudflare's browser grid.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_session_acquire`
- **Parameters:**
  - `keepAlive` (number, default: 60000): Inactivity timeout in milliseconds.
  - `recording` (boolean): Record session screencast.
  - `location` (string): Geolocation routing.
  - `guardrails`: `{ allowedDomains: string[], allowedDomainSets: string[] }`.
  - `targets` (boolean): Return DevTools page targets immediately upon acquisition.
- **Output:** `{ success: true, sessionId: string, targets: [...], webSocketDebuggerUrl, devtoolsFrontendUrl }`

4.3.2 `browser_run_sessions_list`
- **Purpose:** Lists active sessions, historical records, and account concurrency limits.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_sessions_list`
- **Parameters:**
  - `sessionId` (string, optional): Query a specific session.
  - `includeHistory` (boolean, default: false): Include closed sessions.
  - `includeLimits` (boolean, default: true): Include account limit quotas.
- **Output:** `{ activeSessions: [...], history?: [...], limits?: { maxConcurrentSessions, allowedBrowserAcquisitions, usedBrowserTimeSeconds } }`

4.3.3 `browser_run_session_close`
- **Purpose:** Explicitly closes an active browser session and frees resources.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_session_close`
- **Parameters:**
  - `sessionId` (string, required).
- **Output:** `{ success: true, sessionId, status: "closed" }`

4.3.4 `browser_run_live_view`
- **Purpose:** Mints an authenticated Human-in-the-Loop Live View URL for real-time 
  visual inspection or human takeover.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_live_view`
- **Parameters:**
  - `sessionId` (string, required).
  - `mode` (`'devtools'` | `'tab'` | `'full'`, default: `'devtools'`).
  - `targetId` (string, optional): Specific DevTools page target.
  - `expiresInMs` (number, default: 600000): Link expiration in ms.
  - `readonly` (boolean, default: false): Enforces read-only guardrails to prevent 
    human viewers from clicking or typing into the agent's browser.
- **Output:** `{ success: true, sessionId, devtoolsFrontendUrl, webSocketDebuggerUrl, mode, readonly }`

4.3.5 `browser_run_devtools`
- **Purpose:** Executes typed DevTools JSON endpoints on an active session.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_devtools`
- **Parameters:**
  - `sessionId` (string, required).
  - `action` (required enum):
    - `'getVersion'`: Browser, Protocol, V8, and WebKit versions.
    - `'getProtocol'`: Full DevTools Protocol domain and command schema.
    - `'listTargets'`: List open tabs, service workers, and iframes.
    - `'getTarget'`: Inspect a specific target.
    - `'newTarget'`: Open a new tab (`url` optional).
    - `'activateTarget'`: Bring tab to foreground.
    - `'closeTarget'`: Close a specific tab.
  - `targetId` (string): Required for getTarget, activateTarget, closeTarget.
  - `url` (string): Optional URL for newTarget.
- **Output:** Standard DevTools JSON protocol response.

4.3.6 `browser_run_cdp_command`
- **Purpose:** Directly executes arbitrary raw Chrome DevTools Protocol commands 
  over WebSocket (`sendCdpCommand`). Auto-launches a session if `sessionId` is omitted.
- **UI Resource URI:** `ui://spike-land/browser-run/browser_run_cdp_command`
- **Parameters:**
  - `method` (string, required): CDP method name (e.g. `'Page.navigate'`, 
    `'Runtime.evaluate'`, `'DOM.getDocument'`, `'Network.enable'`).
  - `params` (object, optional): CDP command arguments.
  - `sessionId` (string, optional): Existing session ID. If omitted, launches 
    a session automatically.
  - `targetId` (string, optional): Pin WebSocket connection to a specific page target.
  - `keepSessionOpen` (boolean, default: false): When true, leaves an auto-launched 
    session open after the command completes.
- **Output:** `{ success: true, method, sessionId, result: { ... } }`

5. DEPLOYMENT ARCHITECTURES & INTEGRATION PATTERNS

The Browser Run suite is accessible through five distinct integration patterns, 
enabling everything from lightweight CLI agents to full-scale enterprise swarms:

         └──────────────────┴────────┬────────┴──────────────────┴──────────────────┘

5.1 Standalone Dedicated Worker (`workers/browser-run-mcp`)
A self-contained Cloudflare Worker (`spike-browser-run-mcp`, version `2.0.0-mcp2026`):
- Entrypoint: `workers/browser-run-mcp/src/index.ts`
- Canonical URI: `https://spike-browser-run-mcp.spikeland.workers.dev`
- Exposes standard MCP 2026-07-28 JSON-RPC at `/mcp` and `/`.

5.2 Spike Land Platform Gateway Integration (`spike-vinext`)
All 18 tools are imported into `lib/mcp-gateway.ts` and registered in `ALL_TOOLS`.
- Grouped into the `"Browser Run"` capability category (`id: "browser-run"`, count: 18, 
  riskTier: `"low-readonly"`, icon: `"globe"`).
- Accessible through the global `/api/mcp` endpoint and web UI playground at `/mcp`.

5.3 Pattern B: Progressive Disclosure Broker
In the main platform MCP gateway, exposing 18 tools upfront is avoided to preserve 
the LLM's Position-Zero cache:
1. Agent connects and receives only the 5 Broker Meta-Tools.
2. Agent calls `list_capability_categories()` -> sees `"browser-run"` (18 tools).
3. Agent calls `configure_active_categories({ enable_categories: ["browser-run"] })`.
4. Schemas for all 18 tools are disclosed **in-band in the tool response body**, 
   leaving the native `tools/list` invariant.
5. Agent calls `execute_tool({ tool_name: "browser_run_markdown", arguments: { ... } })`.

5.4 Pattern C: Virtual Scoped Gateway (`/api/mcp/g/browser-run`)
For agents that cannot handle Broker indirection (e.g. lightweight models or direct 
Cursor `.cursor/mcp.json` configs):
- The dedicated URL `/api/mcp/g/browser-run` represents an RFC 8707 Canonical Server.
- When an agent calls `tools/list` on this endpoint, the gateway returns all 18 
  Browser Run tools natively without requiring category activation.
- `GET /api/mcp/g/browser-run` returns metadata diagnostics and tool inventories.

5.5 Universal Gateway & Multi-Registry Integration

6. PROTOCOL CONFORMANCE, HARDENING & SECURITY
================================================================================
The Browser Run implementation conforms to the highest standards of the Model 
Context Protocol and edge security governance:

6.1 Stateless MCP 2026-07-28 & Multi-Era Compatibility
- **Stateless Operation:** Operates without requiring stateful `initialize` handshakes 
  or sticky `Mcp-Session-Id` headers (SEP-2567).
- **Multi-Era Support:** Supports `2026-07-28`, `2025-11-25`, and `2024-11-05`. If 
  a legacy client calls `initialize`, the worker returns server capabilities 
  gracefully. If an unsupported version is requested, returns standard SEP-2575 errors.

6.2 SEP-2243 Header Desynchronization Defense (`-32020 HeaderMismatchError`)
To prevent HTTP smuggling, desynchronization attacks, or proxy tampering:
- If the HTTP request contains `Mcp-Method` header, it MUST strictly match the 
  JSON-RPC `method` in the body.
- If the HTTP request contains `Mcp-Name` header, it MUST strictly match `params.name`.
- Mismatches immediately abort with HTTP 400 and JSON-RPC error `-32020`.

6.3 SEP-2575 Protocol Version Negotiation (`-32022 UnsupportedProtocolVersionError`)
- Inspects `_meta["io.modelcontextprotocol/protocolVersion"]`, `MCP-Protocol-Version` 
  header, or `params.protocolVersion`.
- Validates against supported versions `["2026-07-28", "2025-11-25", "2024-11-05"]`.
- Rejects invalid versions with HTTP 400 and error `-32022`.

6.4 SEP-2549 Deterministic Caching & Position-Zero Prompt Cache Preservation
- `tools/list` responses on dedicated endpoints return deterministic `CacheableResult` 
  with `ttlMs: 3600000` and `cacheScope: "public"`.
- Tools are sorted alphabetically by name to ensure bit-for-bit cache reproducibility.

6.5 RFC 9728 OAuth 2.1 Protected Resource Metadata
- Dedicated worker serves `GET /.well-known/oauth-protected-resource` conforming to 
  RFC 9728:
  - `resource`: Canonical worker URI.
  - `authorization_servers`: `["https://auth.spike.land/oauth2"]`.
  - `scopes_supported`: `["mcp:tools:read", "mcp:tools:execute", "browser-rendering:read", "browser-rendering:write"]`.
  - `token_passthrough_prohibited: true`.
  - `rfc8707_audience_binding_required: true`.

6.6 Security Guardrails: Read-Only Live View & Domain Whitelisting
- **Read-Only Mode:** `browser_run_live_view` supports `readonly: true`, setting 
  `guardrails: { mode: "readonly" }` so viewers cannot inject keyboard or mouse events.
- **Domain Guardrails:** `browser_run_session_acquire` accepts `guardrails.allowedDomains` 
  to restrict browsing strictly to approved domains.
